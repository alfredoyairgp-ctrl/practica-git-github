# Práctica de Git y GitHub

Este repositorio fue creado como parte de una práctica académica
para aprender el funcionamiento básico de Git y GitHub.

## Objetivos

- Crear un repositorio en GitHub.
- Realizar commits.
- Trabajar con archivos dentro del repositorio.
- Comprender el control de versiones.
- Aprender a utilizar ramas y Pull Requests.
